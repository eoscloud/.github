# Support

The repositories of github.com/eoscloud contain open source tools for the
eoscloud platform. Where to go depends on what you need:

- **Questions about using or contributing to a project:** start a discussion in
  the repository's Discussions tab.
- **Bugs and feature requests:** open an issue in the repository, using one of
  the forms. Please search existing issues first.
- **Security vulnerabilities:** never open a public issue. Follow SECURITY.md in
  the repository.
- **Your eoscloud account, billing or a service incident:** GitHub issues are
  not customer support. Write to support@eoscloud.io, or ask in the netcup
  forum: https://forum.netcup.de/board/86-netcup-eos/
- **Documentation:** https://docs.eoscloud.io

The maintainers look at issues, discussions and pull requests on a best-effort
basis; there is no guaranteed response time outside of SECURITY.md.
