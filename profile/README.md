# eoscloud

Open source tools for the [eoscloud](https://eoscloud.io) platform.

| Repository | Description |
| --- | --- |
| [go-eoscloud](https://github.com/eoscloud/go-eoscloud) | Go SDK for the eoscloud API (`go.eoscloud.io/go-eoscloud`) |
| [eoscloud-mcp](https://github.com/eoscloud/eoscloud-mcp) | MCP server that gives AI assistants access to eoscloud |
| [terraform-provider-eoscloud](https://github.com/eoscloud/terraform-provider-eoscloud) | Terraform and OpenTofu provider for eoscloud |

Documentation: https://docs.eoscloud.io

Contributions are welcome. Each repository has its own CONTRIBUTING.md and
SECURITY.md; all of them follow our
[code of conduct](https://github.com/eoscloud/.github/blob/main/CODE_OF_CONDUCT.md).
